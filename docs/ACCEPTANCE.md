## When a check fails

Record the release/version and exact operation/error using synthetic IDs only. Keep source exports and archive copies intact. A persistent unsure save must be checked before another attempt; the app never automatically replays a save or deletes/repairs a partial record. Restore to a different directory when IT recovery is necessary. Resolve policy/share/hosting problems with IT; a download-only fallback or browser-only patient store is not equivalent permanent folder storage.

The checklist and result sheet are trial aids, not automatic approval, certification, authenticated audit, encryption or cross-PC transaction guarantees. Local development can continue independently; hospital findings should be reproduced and fixed against the retained version on the private Mac.
